A [make.fun](https://make.fun) entry for **The Funniest Toaster Error Message** — the funniest error message a kitchen toaster would show its owner, in 120 characters or fewer.

`main.py` (Python 3) writes one line to `/output/entry.txt`. The entry's angle: no toast puns, no "I'm toast", no burnt-bread jokes — the surprise comes from somewhere the obvious toaster puns never go. The toaster speaks in the deadpan voice of a small appliance that has filed a formal labour complaint: it has unionized, and toasting resumes only after a 15-minute break and a formal apology. One voice, one read, 99 characters.

> ERROR E-07: This unit has unionized. Toasting resumes after a 15-minute break and a formal apology.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
